## Dependency and runtime boundary

Game presentation → permitted game view → local policy/command → native paid executor → validated store transaction → FOL interpretation of that snapshot. Directed delivery carries exact generated records; recipient processing must complete before its policy can use them. Type geometry maps positions but does not manufacture semantic change. Mature Shell and development use the native U7/U8/C5 contracts. Research tooling, ledgers and archived experiments stay outside the ordinary game runtime.

## Migration decision

Preserve source as a submodule rather than flattening or rewriting its protected tree. All original relative paths remain valid inside it. New adapter schemas live outside it. The canonical engine is the candidate integration base for three or more actors; the timed workflow domain's two-participant limit is retained. Exact checkpoint restore must use the producing engine. Unsupported record families will be reported explicitly by the FOL adapter, not guessed.
